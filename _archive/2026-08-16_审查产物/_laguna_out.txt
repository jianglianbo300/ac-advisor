## 1. LongCat 方案批判性审查

### 方案 1: 预测性控制（RH 回升斜率预测）
**缺陷**：
- **环境干扰**：室外湿度变化剧烈（下雨、降温），线性预测失效
- **滞后性**：2分钟决策周期无法捕捉快速变化，预测误差放大
- **冷启动问题**：刚关机时缺乏足够历史数据

**风险**：误判导致频繁开关，能耗增加 15-20%

### 方案 2: 个性化学习
**遗漏**：
- **采样偏差**：用户干预多为极端情况，不代表正常偏好
- **时间衰减**：学习数据未加权衰减，过去偏好可能过时
- **多用户冲突**：未处理不同用户偏好的冲突

**风险**：学习结果导致舒适度下降

### 方案 3: COP 寻优
**缺陷**：
- **维度灾难**：仅按目标温度分组，忽略湿度、时间、环境因素
- **数据污染**：异常数据（门窗开启）未过滤， skew 优化结果
- **静态分组**：未考虑动态环境变化，分组结果滞后

**风险**：优化方向错误，实际 COP 下降

### 方案 4: 异常检测
**遗漏**：
- **缺氟检测**：仅凭湿度回升无法区分缺氟/门窗，误报率高
- **传感器漂移**：未建立基线对比机制，漂移难以早期发现
- **门窗检测**：单一湿度阈值易受环境湿度干扰

**风险**：误报导致正常运行中断

### 方案 5: 虚拟变频
**隐含风险**：
- **升温滞后**：升温后制冷效果减弱，湿度可能回升
- **边界条件**：接近达标时升温，可能错过最佳关机时机

### 方案 6: MIN_RUN/MIN_OFF 自适应
**缺陷**：
- **收敛慢**：环境变化快，自适应参数跟不上
- **震荡风险**：自适应参数调整不稳定，导致系统震荡

## 2. 已实施虚拟变频代码审查

### 潜在 Bug：
```python
# 升温逻辑存在竞争条件
if (hum <= VIRTUAL_INV_APPROACH_RH  # 58%
    and comp_min >= A.MIN_RUN       # 40min
    and current_target < VIRTUAL_INV_MAX_TARGET  # <26°C
    and minutes_since_last_adjust >= DEHUM_ADJUST_COOLDOWN):
    new_target = min(VIRTUAL_INV_MAX_TARGET, current_target + 1)
```

**问题**：
1. **升温后降湿效率下降**：升温 1°C 降低制冷能力 8-12%，湿度去除速率显著下降
2. **时机选择错误**：在 `hum <= 58%` 时升温，可能导致湿度回升至 60%+
3. **缺乏降温补偿**：升温后未监控湿度回升，错失重新降温机会

### 副作用：
- **能耗增加**：升温后运行时间延长 10-15%
- **舒适度下降**：升温期间温感升高

## 3. 补充更智能方案

### 方案 A: 动态湿度带控
**原理**：根据室外湿度和温度动态调整除湿目标带
```python
# 新增逻辑
outdoor_hum_impact = get_outdoor_humidity_impact()  # 通过历史数据建模
dynamic_dehumid_band = DEHUMID_EXIT_RH + outdoor_hum_impact * 0.3
if hum <= dynamic_dehumid_band:
    return ("off", None, "动态湿度带控达标")
```
**优势**：减少 20-30% 能耗，提升舒适度

### 方案 B: 复合负载预测
**原理**：结合温湿度梯度和压缩机运行效率预测最优关机时间
```python
# 计算剩余除湿时间
remaining_dehumid_time = (hum - DEHUMID_EXIT_RH) / abs(delta_rh_20min) * 20
# 结合能效衰减
if remaining_dehumid_time < 15 and comp_min > 30:
    return ("off", None, "复合负载预测优化关机")
```

### 方案 C: 分段式目标温度优化
**原理**：在除湿周期内分段调整目标温度，先强力除湿后缓除
```python
if comp_min < 20:  # 前20分钟强力除湿
    target = 24
elif comp_min < 40:  # 中间缓除
    target = 25
else:  # 后期维持
    target = 26
```

### 方案 D: 环境自适应阈值
**原理**：根据季节和历史数据自适应调整所有阈值
```python
season_factor = get_season_humidity_factor()  # 夏季湿度更易回升
DEHUMID_EXIT_RH_ADAPTIVE = DEHUMID_EXIT_RH + season_factor
```

## 工程落地建议

1. **立即修复虚拟变频逻辑**：在升温后 5分钟内监控湿度回升，必要时降温补偿
2. **添加异常过滤**：在 COP 寻优前过滤门窗开启数据（通过风速/PM2.5判断）
3. **实现动态湿度带控**：优先级最高，预期节能 25%
4. **复合负载预测**：替代单一 RH 阈值判断，提升决策准确性
